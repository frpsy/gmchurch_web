# 주보·순서지 작업 배운 점 (2026-11-22 기준)

## 기도서
- 기도서 본문은 저작물이다. 저장소와 대화에 옮겨 적지 않는다. 쪽 번호, 출처, 순서 구조만 기록한다.
- 본문 검수는 Claude가 직접 한다. 온라인 기도서와 줄 단위 일치 여부만 확인하고, 본문은 외부 AI에 보내지 않는다.
- 쪽 번호는 주보에 인쇄된 값을 따른다. 2026-11-22 성체나눔은 인쇄 269쪽이었고, 기록은 270쪽이었다. 사진으로 269쪽이 성체 나눔임을 확인했다.
- 본기도 본문은 기도자가 읽으므로 순서지에 싣지 않는다(이번 주 사용자 지시). 사제 인사, 기도합시다, 회중 응답만 싣는다.
- 온라인 기도서에는 쪽 번호가 없다. 쪽 번호 확인은 실물 사진으로 한다.

## 독서 본문
- 독서 참조의 책 이름이 화면의 성경 책 목록에 없으면 본문이 비고 "말씀 본문을 준비 중입니다"만 보인다. 2026-11-22 제2독서(에페소), 2026-11-08 제2독서(야고보)가 이 때문에 비었다.
- 재발 방지: `tests/readingsResolve.test.js`가 주차별 독서 항목과 readings.json 키의 책 이름을 검사한다. 책 이름을 추가하면 이 목록도 함께 본다.

## 검수
- 외부 AI 시각 판독은 이름을 잘못 읽을 수 있다(장순희 → 장춘희). 불일치는 주보를 직접 확대해서 확인한 뒤 고친다.
- 주보에 인쇄되지 않는 항목(예물 기도, 성찬기도, 영성체, 파송 등)은 불일치로 보고하지 않는다.
- 순서가 바뀐 경우가 있었다(성체나눔과 하느님의 어린양). 주보 순서를 한 줄씩 대조한다.

## 악보 이미지
- 원본 스캔의 검은 테두리는 가장자리 밝기로 찾아 자른다. 원본을 자르면 `manifest.json`의 해시와 크기를 갱신해야 `tests/hymnalImages.test.js`가 통과한다.

## 배포
- 개발 머지 뒤 `scripts/release-official.sh` → 공식 PR → squash 머지 순서로 공식 반영한다. 공식 PR이 없으면 반영되지 않는다.
- 공식 반영 주기: 평소 최대 2시간, 주일 10~11시 사이는 10분 간격(공식 담당자 안내).
- 검사가 진행 중이면 반복 조회하지 않는다. 다음 턴에 한 번 확인하고 머지한다.

## 도구
