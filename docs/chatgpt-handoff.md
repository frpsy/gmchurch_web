# ChatGPT 인계 안내 — 광명교회 홈페이지

ChatGPT가 이 저장소(`frpsy/gmchurch_web`)를 이어받아 **받아오기 → 수정 → 커밋 → PR**까지 하도록 하는 안내서입니다.
아래 **2. 붙여넣기 안내문**을 ChatGPT 대화창에 그대로 복사해 붙여넣으면 됩니다.

---

## 1. 먼저 할 준비 (사람이 1회)

ChatGPT가 저장소에 손을 대는 방법은 두 가지입니다. 편한 쪽을 고르세요.

### A. ChatGPT의 코딩 에이전트(Codex)로 직접 작업 — 권장
1. ChatGPT에서 Codex를 열고 **GitHub 계정을 연결**합니다.
2. 연결할 저장소로 **`frpsy/gmchurch_web`** 를 선택합니다.
3. 작업을 맡기면 Codex가 브랜치를 만들고 수정한 뒤 **PR(변경 요청)** 을 올립니다. 머지는 GitHub에서 확인 후 누르거나, 안내문에 따라 Codex에게 맡깁니다.
4. Codex는 저장소의 `AGENTS.md`를 자동으로 읽으므로 규칙을 따로 설명하지 않아도 됩니다.

> 메뉴 이름·연결 화면은 ChatGPT 업데이트에 따라 달라질 수 있습니다. "GitHub 연결", "저장소 선택" 단계만 찾으면 됩니다.

### B. 일반 ChatGPT 대화 + 내 컴퓨터에서 실행
ChatGPT가 수정할 코드와 명령어를 알려 주고, 실행은 사람이 합니다.
```bash
git clone https://github.com/frpsy/gmchurch_web.git
cd gmchurch_web
npm ci
npm test
```
수정 후에는 ChatGPT가 알려 주는 `git add` / `git commit` / `git push` 명령을 그대로 실행하고, GitHub에서 PR을 만들어 머지합니다.

### 다른 사람(다른 GitHub 계정)이 함께 작업한다면
GitHub 저장소 → **Settings → Collaborators → Add people** 에서 그 계정을 초대해야 push할 수 있습니다.
ChatGPT·Codex가 **내 계정**으로 작업할 때는 초대가 필요 없습니다.

## 2. 붙여넣기 안내문 (이 블록 전체를 복사)

````text
너는 지금부터 "대한성공회 광명교회" 홈페이지 GitHub 저장소 frpsy/gmchurch_web 의 공동작업자다.
이전 작업은 다른 AI(Claude)가 했고, 너는 같은 규칙으로 이어서 작업한다.

[프로젝트]
- 사이트: https://frpsy.github.io/gmchurch_web/ (GitHub Pages, main 머지 시 자동 배포)
- 바닐라 HTML+CSS+JS, 빌드 없음. 콘텐츠는 전부 data.js의 CHURCH_DATA, 화면은 app.js 렌더러가 그림
- 테스트: npm test (Vitest 90개, 반드시 통과)
- 규칙 원본: 저장소의 CLAUDE.md (요약: AGENTS.md). 작업 전에 두 파일을 먼저 읽어라.

[작업 순서 — 매번]
1. git fetch origin main → git checkout -b chatgpt/작업명 origin/main
2. 수정 (콘텐츠는 data.js에만, HTML에 문구 직접 쓰기 금지)
3. npm test 통과 + AGENTS.md의 nav 검증 명령 실행
4. git add 수정한파일 (git add -A 금지) → git commit -m "fix: 한국어로 무엇을 왜"
5. git push -u origin chatgpt/작업명 → PR 생성 (본문에 변경 내용·검증 결과를 한국어로)
6. 저장소 정책상 PR은 확인 없이 squash merge. 단, 내가 "머지 전에 보여줘"라고 하면 멈춰라.

[절대 규칙]
- main에 직접 push 금지. 항상 브랜치 → PR.
- 색은 CSS 변수만(#hex 하드코딩 금지). 다크모드(prefers-color-scheme: dark)에서도 글자가 읽혀야 한다.
- 새 CSS 클래스 전에 ARCHITECTURE.md의 기존 클래스부터 확인.
- 전례독서 병합 규칙은 scripts/lib/lectionary.js와 app.js(_applyOverrides) 두 곳 — 함께 수정.
- 주보·성서 본문은 추측 금지. 주보에 인쇄된 값, 공동번역 본문만 쓴다.
- 모르는 사실(날짜·이름·출처)을 지어내지 말고 나에게 물어라.

[문체·용어 — 대한성공회 기준]
- 정중하고 담백하게, 꾸밈말(아름다운·따뜻한·늘·든든한) 금지
- 하느님(하나님 X), 공현절(주현절 X), 감사성찬례
- 성서 책 이름은 공동번역: 마태·마르코·루가·요한, 창세·출애굽, 에페소·필립비·골로사이, 에제키엘, 즈가리야 / 반절은 상·하

[화면을 바꿨다면]
휴대폰 폭 320px·390px과 다크모드에서 확인: 가로 스크롤, 글자 잘림, 버튼 겹침이 없어야 한다.

[보고 방식]
작업이 끝나면 한국어로 짧게: 무엇을 바꿨는지, 어떻게 확인했는지(테스트 결과 포함), 내가 결정해야 할 것.

준비됐으면 CLAUDE.md와 AGENTS.md를 읽고, 이해한 핵심 규칙을 5줄로 요약한 뒤 내 첫 요청을 기다려라.
````
