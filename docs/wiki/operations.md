# 운영 흐름 요약

상세 절차는 `CLAUDE.md` "주보 등록 절차", 표기는 `../church-glossary.md`가 원본이다.

## 주보를 받았을 때 (묻지 않고 끝까지)
0. **먼저 위키를 읽는다**(`church.md`의 사람·직함, `../church-glossary.md`). 이미지에서 읽은 이름·세례명은 위키·`data.js`와 대조해 맞추고, 대조할 수 없는 이름은 읽은 대로 적되 보고에 `미확인`으로 알린다.
1. 이미지를 `bulletins/YYYYMMDD_N.jpg`로 저장(표지부터).
2. 3면 예배 순서면에서 제1독서·성시·제2독서·복음을 읽어 `data/lectionary-overrides.json` 기록. 연속 서사면 트랙 A(성시가 표준과 다르면 `psalm`), 예언서·복음 짝이면 트랙 B, 특별 주일은 `koreanName`+`readings`. 3면 오른쪽 아래 `다음 주일 봉사자` 표로 **다음 주 독서·성시**도 기록한다.
3. 4면 교회소식을 `data/bulletin-news.json`에 기록(■ 항목 하나 = `{title, body}`, `일시 :` 줄은 `\n`). 통계·헌금 명단은 제외.
4. 핵심구절을 `data/bulletin-verses.json`에 기록(`{ref, text}`). 주보에 인쇄돼 있으면 그것, 없으면 그 주 복음에서 1~3절을 직접 골라 알린다. 본문은 `bible/`의 공동번역 PDF(`pdftotext -layout`)에서 글자 대조해 그대로 옮기고 절 번호·각주 기호는 넣지 않는다.
5. 3면 예배 순서를 `data/worship-order.json`에 기록(`†`는 `stand`, 오른쪽 칸은 `by`). `node scripts/build-worship-slides.js` → ℹ️ 안내 확인 → `/presentation/worship/`(슬라이드)·`book.html`(예식문)에서 눈으로 확인. → `liturgy.md` "예배 슬라이드"
6. `node scripts/sync-bulletins.js` → 경고 확인 → `npm test` → `bulletin.html`(이번 주 말씀 카드)·`news.html`을 눈으로 확인.
7. 커밋·푸시·PR·squash 머지까지 자동. **보고는 `머지했습니다`(+PR 링크)만.** 처리할 것 없는 PR 알림은 보고하지 않는다.

## 검수 원칙
원문 대조, 의미 유지, 교정은 띄어쓰기·약어(G.F.S.)·표기 통일·날짜 형식·명백한 오탈자만. 새로 알게 된 것은 `church-glossary.md`와 이 위키에 확인된 사실만 추가.

## 모바일 주보 배포와 성가

- **모바일 주보 배포 원칙 (2026-11-01 사용자 확정)** — 모바일 주보와 본문·성가 악보 이미지는 공개 저장소에 반영하고 GitHub Pages의 `/jubo/`에 웹 배포한다(사용자 명시 승인, 2026-11-01). 교우가 웹에서 열어 보도록 하되, 링크 안내는 비공개 교회 밴드에서만 한다. 공개 홈페이지 본문·메뉴·푸터·사이트맵·공개 게시물에는 모바일 주보 링크나 홍보를 추가하지 않는다. “홈페이지에 게시하지 않는다”는 웹 배포 금지가 아니라 홈페이지에서 연결·홍보하지 않는다는 뜻이다. 이 범위의 커밋·푸시·PR·머지는 기존 자동 처리 절차로 진행하며 공개 접근 가능성을 이유로 매번 재승인을 요청하지 않는다. 비공개 밴드에 링크를 올려도 공개 저장소/GitHub Pages의 대상 파일 자체가 비공개로 전환되지는 않는다. 원본 PDF·악보 이미지의 공개 여부와 검색 제외는 별도로 관리하고, robots.txt나 링크 숨김만으로 비공개·검색 제외가 완료됐다고 기록하지 않는다.
- **성가 악보 원칙 (2026-11-01 사용자 확정)** — 단성판을 기본으로 사용하고 수록되지 않은 곡은 전체판에서 가져온다. 해당 곡의 악보 이미지를 그대로 기존 토글 안에 넣는다. PDF 전체 열기나 #page 링크로 대체하지 않는다. 원본 파일명은 영어로 단성판(unison)·전체판 및 분할 번호(part-01 등)를 구분하고, 문서의 자료명은 ‘성가’로 기록한다.

- **고령 교우의 화면 이동 최소화 (2026-11-01 사용자 확정)** — 예배 중 필요한 성경 말씀 전문·설교의 바탕 본문·기도문·성가 악보는 모바일 주보의 해당 항목 안에서 펼쳐 읽는다. 설교 항목에도 해당 성경 본문 전문을 표시한다. 실제 설교 원고 전문은 제공받은 경우에만 싣고 임의로 만들지 않는다. 악보를 눌러 새 탭·이미지 화면으로 이동시키지 않고 현재 화면에서 두 손가락 확대를 이용한다. 자료가 빠졌다고 외부 링크로 대체하지 말고 원문을 확보해 보완한다. 안내 영역의 선택적 외부 링크와 예배 중 필수 자료를 구분한다.
