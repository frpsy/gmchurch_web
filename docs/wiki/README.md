# 광명교회 위키 (Claude 참고용)

홈페이지 전체(2026-10-11 기준)를 읽고 정리한 **내부 참고 문서**다. 사이트 콘텐츠의 원본은 `data.js`이고, 이 위키는 그 내용을 빠르게 찾고 일관되게 쓰기 위한 요약이다. **충돌하면 `data.js`와 실제 페이지가 맞다.**

## 쓰는 법
- 작업 시작 전에 관련 문서를 읽는다: 주보·교회소식 → `operations.md`, `liturgy.md`, `../church-glossary.md` / 사이트 수정 → `site.md` / 소개 문구·FAQ·사역 → `church.md`, `ministries.md`.
- 문서마다 `출처`(data.js 키 또는 페이지)를 달았다. 사실은 출처에서 다시 확인할 수 있어야 한다.
- 새로 알게 된 것은 **확인된 사실만** 해당 문서에 추가한다(추측 금지, 모르면 `미확인`). 사이트 콘텐츠를 바꾸면 같은 PR에서 위키도 갱신한다.
- 이 위키에서 발견한 **사이트 문제**는 `site.md`의 "알려진 이슈"에 적고, 요청 범위가 아니면 임의로 고치지 않는다.
