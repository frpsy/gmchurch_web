# 성능·버그·리팩토링 계획 (2026-11-28)

디자인은 확정되었다. 이 계획의 모든 변경은 **화면이 바뀌지 않아야** 한다. 기준은 `origin/main` `d8628e0`.

## 원칙

1. 화면 고정: 성능·리팩토링 PR은 변경 전후 스크린샷 비교에서 차이가 0이어야 한다(`site-check.mjs compare`). 차이가 나면 그 픽셀이 의도한 것인지 PR에 적는다.
2. PR 하나에 목적 하나. 각 PR은 `npm test` → `site-check.mjs smoke` → 외부 AI 검토(`ai-ask.sh -t review`) → `merge-when-green.sh` → 공식 반영 → 배포 사이트 확인.
3. 빌드 단계는 들이지 않는다(빌드 없는 정적 사이트 유지).
4. 수치는 `site-check.mjs perf`로 잰다. 고친 뒤 같은 명령으로 다시 재서 PR에 전후 표를 붙인다.

## 원인 진단 (`why`)

- **흔들림**: 흔들림이 일어나는 시각이 DCL(스크립트 실행 끝)과 겹친다. `defer`(#919) 뒤로 HTML 틀이 먼저 그려지고, 렌더러가 섹션을 채우면서 아래 섹션과 푸터를 밀어낸다. 푸터(`#main-footer`)는 모든 페이지에서 0.07~0.09를 낸다. 홈은 `#about-brief`·`.home-hero-image`·`#worship`, 교회 소개는 `#what-is-anglican`·`#priest-section`·`#ack`, 예배는 `#eucharist-order`·`#bcp-hymnal`·`#daily-office`, 교회력은 `#lectionary`·`#seasons`·`#special`, 설교 읽기는 `.sermon-reading-layout`.
- **전송량**: Pretendard CDN 글꼴 조각이 페이지당 290~510KB로 가장 크다. 그다음은 사진(희망터 668KB, 어린이 733KB, 첫 화면 밖 사진도 처음에 받음)이다.
- **LCP**: 갤러리·희망터·순서지는 사진이 늦게 뜬다(지연 로딩·우선순위·크기 후보 점검 필요).
