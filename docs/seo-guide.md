# 검색 노출 안내서 — 구글·네이버

> 광명교회 홈페이지가 구글·네이버 검색에 나오게 하는 방법.
> 개발 지식 없이도 따라 할 수 있게 순서대로 정리했습니다.
>
> 사이트 주소: `https://frpsy.github.io/gmchurch_web/`
> 최종 점검일: 2026-08-02

---

## 0. 먼저 알아둘 것 — 검색은 "등록"이 아니라 "수집"

검색 사이트에 돈을 내고 등록하는 게 아닙니다. 구글·네이버의 **로봇(크롤러)이 우리 사이트를 방문해서 내용을 가져가야** 검색 결과에 나옵니다.

우리가 할 일은 딱 세 가지입니다.

| 단계 | 하는 일 | 소요 |
|---|---|---|
| ① 알리기 | "우리 사이트 여기 있어요"를 각 검색엔진에 신고 | 30분 (1회) |
| ② 확인시키기 | 이 사이트가 우리 것임을 증명 (소유확인) | 10분 (1회) |
| ③ 기다리기 | 로봇이 방문해서 수집 → 검색에 반영 | 구글 3~14일 / 네이버 2~8주 |

**중요**: ③은 정말 오래 걸립니다. 등록 다음 날 검색해보고 "안 된다"고 판단하지 마세요.

## 1. 지금 우리 사이트 상태 (2026-08-02 점검)

### ✅ 이미 되어 있는 것 — 손댈 필요 없음

| 항목 | 상태 |
|---|---|
| `robots.txt` (로봇 출입 허용) | ✅ 있음 |
| `sitemap.xml` (페이지 목록 16개) | ✅ 있음 |
| 페이지마다 제목(title)·설명(description) | ✅ 19개 전 페이지 |
| `canonical` (중복 주소 정리) | ✅ 19개 전 페이지 |
| 카톡·페북 공유 이미지(og:image) | ✅ 있음 |
| 교회 정보 구조화 데이터(주소·전화·예배시간) | ✅ index / clergy / visit |
| 구글 소유확인 코드 | ✅ 심어져 있음 |
| 비공개 페이지 처리 (주보·사진첩·개인정보) | ✅ noindex, 사이트맵에서도 제외 |

기술적인 준비는 거의 끝난 상태입니다.

### ❌ 아직 안 된 것 — 이 문서에서 할 일

| 항목 | 조치 |
|---|---|
| **네이버 소유확인 코드가 없음** | → 3장 |
| **네이버 서치어드바이저에 사이트 미등록** | → 3장 |
| 구글 서치콘솔에서 사이트맵 제출 여부 미확인 | → 2장 |
| 네이버 지도/플레이스 등록 | → 5장 |
| 네이버 로봇은 우리 사이트 내용을 거의 못 읽음 | → 4장 (⚠️ 가장 중요) |

## 2. 구글 — 3단계

구글은 이미 소유확인 코드가 심어져 있으니, **서치콘솔에 들어가서 확인만** 하면 됩니다.

### 2-1. 서치콘솔 접속

1. <https://search.google.com/search-console> 접속
2. 교회 구글 계정으로 로그인
3. 왼쪽 위에 `frpsy.github.io/gmchurch_web/`가 보이면 → 이미 등록됨, **2-2로**
4. 안 보이면 → `속성 추가` → **`URL 접두어`** 선택 → `https://frpsy.github.io/gmchurch_web/` 입력
   - 소유확인 방법 중 **`HTML 태그`** 선택 → 이미 코드가 심어져 있으므로 `확인` 누르면 바로 통과됩니다.
   - ⚠️ `도메인` 방식은 고르지 마세요. github.io는 우리 소유가 아니라서 불가능합니다.

### 2-2. 사이트맵 제출 (1회만)

왼쪽 메뉴 `색인 > Sitemaps` → 입력창에 아래를 넣고 `제출`

```
sitemap.xml
```

`성공`이라고 뜨고 `발견된 URL 16`이 나오면 정상입니다.

### 2-3. 빠른 색인 요청 (선택)

새 페이지를 만들었거나 급할 때:

1. 맨 위 검색창에 페이지 주소 전체를 붙여넣기 (예: `https://frpsy.github.io/gmchurch_web/worship.html`)
2. `색인 생성 요청` 클릭
3. 하루 10건 정도가 한도. 중요한 페이지 위주로.

### 2-4. 잘 됐는지 확인

구글 검색창에 아래를 그대로 입력:

```
site:frpsy.github.io/gmchurch_web
```

우리 페이지들이 목록으로 나오면 성공입니다. **등록 후 3~14일 뒤부터** 확인하세요.

## 3. 네이버 — 5단계

네이버는 **처음부터 다** 해야 합니다. 시간은 20분쯤 걸립니다.

### 3-1. 서치어드바이저 가입 & 사이트 등록

1. <https://searchadvisor.naver.com> 접속 → 네이버 계정으로 로그인
2. 오른쪽 위 `웹마스터 도구` 클릭
3. 사이트 입력창에 아래 주소를 넣고 `+` 클릭

```
https://frpsy.github.io/gmchurch_web/
```

> ⚠️ 맨 끝 슬래시(`/`)까지 정확히 넣으세요.

### 3-2. 소유확인 코드 받기

1. `HTML 태그` 방식 선택
2. 아래 같은 코드가 나옵니다 (`content` 안의 값은 사람마다 다릅니다)

```html
<meta name="naver-site-verification" content="여기에긴영문숫자" />
```

3. 이 줄을 **통째로 복사**해 두세요. **아직 `확인` 버튼은 누르지 마세요.**

### 3-3. 코드를 사이트에 붙여넣기

`index.html` 파일을 열고, 이미 있는 구글 코드 **바로 아래 줄**에 붙여넣습니다.

```html
    <meta name="theme-color" content="#163d24">
    <meta name="google-site-verification" content="lQf88exnyoxIdRSjr9znrkU1toQBuFDp3UwVfxTDxhs">
    <meta name="naver-site-verification" content="여기에받은값">   ← 이 줄 추가
    <link rel="canonical" href="https://frpsy.github.io/gmchurch_web/">
```

> 📌 **index.html에만** 넣으면 됩니다. 다른 페이지는 필요 없습니다.

그다음 저장 → 커밋 → `main`에 반영 → **1~2분 뒤** GitHub Pages에 실제로 올라갑니다.

배포됐는지 확인: 브라우저에서 사이트를 열고 `Ctrl+U`(맥은 `⌘+⌥+U`) → 소스에서 `naver-site-verification`이 보이면 OK.

### 3-4. 소유확인 누르기

네이버 화면으로 돌아가 `소유확인` 클릭 → 자동입력 방지 문자 입력 → 완료.

> ❗ 실패하면 대부분 **아직 배포가 안 끝난 것**입니다. 5분 기다렸다 다시 시도하세요.

### 3-5. 사이트맵·robots 제출

왼쪽 메뉴에서 순서대로:

| 메뉴 | 입력값 |
|---|---|
| `요청 > 사이트맵 제출` | `sitemap.xml` |
| `검증 > robots.txt` | `수집 요청` 눌러 확인 |
| `요청 > 웹 페이지 수집` | 중요한 페이지 주소를 하나씩 (하루 50건 한도) |

**수집 요청은 이 순서로 넣으세요** (중요한 순):

```
https://frpsy.github.io/gmchurch_web/
https://frpsy.github.io/gmchurch_web/worship.html
https://frpsy.github.io/gmchurch_web/visit.html
https://frpsy.github.io/gmchurch_web/newcomer.html
https://frpsy.github.io/gmchurch_web/clergy.html
```

### 3-6. 잘 됐는지 확인

네이버 검색창에:

```
site:frpsy.github.io/gmchurch_web
```

또는 `대한성공회 광명교회`로 검색.

**네이버는 구글보다 훨씬 느립니다. 2~8주 기다리세요.**

## 4. ⚠️ 네이버에서 특히 중요한 문제 — 내용이 안 읽힘

### 무슨 일이 벌어지고 있나

우리 사이트는 **글자를 자바스크립트(`app.js`)가 그려 넣는 방식**입니다. HTML 파일 자체에는 빈 상자만 있습니다.

예를 들어 `worship.html`의 실제 파일 내용은 이렇습니다:

```html
<section class="section">
    <div id="worship-services"></div>   ← 비어 있음! 예배 시간은 여기 없음
</section>
```

예배 시간은 `data.js`에 있고, 브라우저가 자바스크립트를 실행해야 비로소 화면에 나타납니다.

- **구글**: 자바스크립트를 실행할 수 있어서 대부분 잘 읽습니다. (다만 며칠 더 걸립니다)
- **네이버**: 자바스크립트 실행이 제한적입니다. 네이버가 공식적으로 명확히 밝힌 적은 없지만, 실무에서는 **JS로 그린 내용이 누락되는 사례가 흔합니다.**

즉 지금 상태로는 **네이버가 우리 사이트를 "제목과 설명만 있고 본문은 텅 빈 페이지"로 볼 가능성이 큽니다.**

### 그래서 어떻게 하나 — 3가지 선택지

| 방법 | 내용 | 난이도 | 추천 |
|---|---|---|---|
| **A. 그냥 두기** | 제목·설명·구조화 데이터는 HTML에 있으니 최소한은 잡힘 | 없음 | 임시 |
| **B. 핵심 내용만 HTML에 직접 넣기** | 예배시간·주소·전화번호 등을 각 페이지 HTML에 요약 블록으로 추가 | 낮음 | ⭐ **권장** |
| **C. 정적 생성(빌드) 도입** | 배포 전에 HTML을 미리 완성시키는 스크립트 추가 | 높음 | 장기 |

### B안 구체적으로

각 페이지 `<main>` 맨 위나 맨 아래에, 화면에는 눈에 띄지 않되 HTML에는 실제로 존재하는 요약 문단을 넣습니다.

```html
<!-- worship.html — 검색엔진용 정적 요약 -->
<section class="sr-only">
    <h2>예배 시간 안내</h2>
    <p>대한성공회 광명교회 주일 감사성찬례는 매주 일요일 오전 11시,
       어린이 예배는 오전 10시입니다.
       경기도 광명시 아방리 2길 10 성 디모테오 성당. 문의 02-2686-0091.</p>
</section>
```

> `sr-only` 클래스는 이미 `style.css`에 있습니다 (화면에는 안 보이고 검색엔진·스크린리더는 읽는 용도).
>
> ⚠️ 단, **화면에 보이는 내용과 다른 글을 숨겨 넣으면 안 됩니다.** 실제 페이지에 나오는 내용을 요약하는 선까지만. 그 이상은 '숨김 텍스트'로 간주돼 불이익을 받습니다.

우선순위 페이지: `index.html`, `worship.html`, `visit.html`, `newcomer.html`, `clergy.html`

## 5. 네이버는 홈페이지보다 "지도"가 먼저 (가장 효과 큼)

한국 사람이 네이버에서 `광명교회`, `광명 성공회`를 검색하면 실제로 위에 뜨는 건 **웹사이트가 아니라 지도(플레이스) 결과**입니다.

**이게 홈페이지 SEO보다 훨씬 빠르고 효과가 큽니다. 아직 안 했다면 1순위로 하세요.**

### 5-1. 네이버 스마트플레이스 등록

1. <https://smartplace.naver.com> 접속 → 네이버 계정 로그인
2. `신규 등록` → 업종에서 **`종교시설 > 교회`** 선택
3. 입력할 내용

| 항목 | 값 |
|---|---|
| 이름 | 대한성공회 광명교회 (성 디모테오 성당) |
| 주소 | 경기도 광명시 아방리 2길 10 |
| 전화 | 02-2686-0091 |
| **홈페이지** | `https://frpsy.github.io/gmchurch_web/` ← **꼭 넣기** |
| 영업시간 | 주일 예배 11:00 |
| 사진 | 성당 외관·내부 5장 이상 |
| 소개글 | 녹색교회, 모든 생명을 환대하는 교회 |

4. 사업자등록증이 없어도 **고유번호증**이나 종교단체 증빙으로 등록 가능합니다.
5. 심사에 3~7일 걸립니다.

### 5-2. 구글 비즈니스 프로필도 함께

같은 개념의 구글 버전입니다. <https://business.google.com> 에서 동일하게 등록하세요.
구글 지도 검색과 "광명교회" 검색 시 오른쪽 정보 카드에 노출됩니다.

복사해서 하나씩 지워가며 쓰세요.

- [ ] 구글 서치콘솔 접속, 사이트 등록 확인
- [ ] 구글 사이트맵 `sitemap.xml` 제출

- [ ] 네이버 사이트맵 제출
- [ ] 네이버 주요 5개 페이지 수집 요청

- [ ] 구글 비즈니스 프로필 등록

**2~4주차 — 개선**
- [ ] 주요 페이지에 정적 요약 블록 추가 (4장 B안)

**매달 1회 — 점검**
- [ ] 구글에 `site:frpsy.github.io/gmchurch_web` 검색 → 페이지 수 확인

- [ ] 새 페이지를 만들었다면 `sitemap.xml`에 추가

## 9. 더 하면 좋은 것 (선택)

### 9-1. 자체 도메인

지금 주소 `frpsy.github.io/gmchurch_web/`는 **남의 도메인 아래 하위 폴더**입니다. 검색엔진이 사이트를 독립된 곳으로 인식하기에 불리합니다.

`gmchurch.or.kr` 같은 도메인(연 1~2만원)을 사서 연결하면:
- 검색 신뢰도 상승
- 주소를 사람들에게 알려주기 쉬움
- 명함·주보에 적기 좋음

연결 방법: 도메인 구입 → GitHub 저장소 `Settings > Pages > Custom domain`에 입력 → `CNAME` 파일 자동 생성 → 사이트맵·canonical 주소 전체 교체.

> ⚠️ 도메인을 바꾸면 **소유확인·사이트맵을 구글·네이버 양쪽에 다시** 등록해야 합니다.

### 9-2. IndexNow

네이버 서치어드바이저는 IndexNow 프로토콜을 지원합니다. 페이지가 바뀔 때 검색엔진에 자동으로 알리는 방식으로, 나중에 GitHub Actions에 붙일 수 있습니다. 지금 단계에서는 필요 없습니다.
