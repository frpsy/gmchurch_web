# 모바일 주보 제작

## 기준과 먼저 읽을 자료
- 기준 화면: https://frpsy.github.io/gmchurch_web/jubo/
- 2026-11-01 사용자 확정. 날짜·본문은 매주 바꾸되 화면 구성과 사용 방식은 유지한다.
- 저장소 루트의 CLAUDE.md(원본), AGENTS.md(요약), jubo/index.html(실제 구현), docs/wiki/operations.md, data/hymnal-2015/README.md를 먼저 읽는다.
- 기존 주보가 기준이다. 새 디자인으로 재구성하거나 기능을 임의로 줄이지 않는다. 사용자 후속 지시가 이 문서보다 우선한다.

## 화면 순서
1. 고정 상단: 광명교회 주보, 호수·날짜, 글자 크기 조절, 공유.
2. 바로가기 탭: 예배 순서 → 교회소식 → 안내.
3. 표지 카드: 주보 그림, 날짜·교회력·호수, 주일명, 집전·설교, 예배 시간, 교구·교회 표어.
4. 이번 주 말씀: 공동번역 본문과 출처.
5. 예배 순서: 인쇄된 주보의 순서·구분을 따르는 접이식 항목, 기립 표시, 회중 응답 구분, 모두 펼치기/접기.
6. 교회소식: 제목과 본문을 카드로 표시.
7. 교회 안내: 주소·전화·봉헌계좌, 복사 버튼, 오시는 길·원본 주보·홈페이지 링크, 자료 출처.
- 다음 주 봉사자 구역·묵상란을 새로 넣지 않는다.
- 모바일 주보에서 홈페이지로 가는 기존 링크와, 공개 홈페이지에서 모바일 주보로 유입시키는 링크를 혼동하지 않는다. 후자는 추가하지 않는다.

## 예배 본문과 악보
- 성경 본문·성가 악보·기도문은 항목을 펼치면 그 자리에서 보인다.
- 성가 악보는 기존 score/scores 필드의 원본 이미지를 그대로 표시한다. 가사만 보여 주거나 PDF 전체 열기·#page 링크로 대체하지 않는다.
- 단성판을 기본으로 하고 해당 곡이 없으면 전체판을 확인한다. 성가 번호·제목·이미지를 대조하고 여러 페이지는 모두 순서대로 넣는다.
- 기존 634쪽 이미지 자료와 새로 받은 782쪽 단성판·811쪽 전체판은 서로 다른 자료다. 페이지 번호·색인을 공유하지 않는다. 새 단성판의 업로드·곡별 매핑 검증이 끝나기 전에는 적용 완료라고 쓰지 않는다.
- 원본 파일명은 영어로 판과 분할 번호를 구분한다. 문서의 자료명은 ‘성가’로 쓴다.
- 복음은 앞 응답 → 본문 → 끝 응답, 본기도는 사제·회중 응답 → 기도 본문 순서를 유지한다.
- 교회와 세상을 위한 기도는 기존 1양식 전문을 유지하며 인도자는 기도자로 표시한다.
- 역할은 p=사제, k=기도자, l=독서자, a=회중이다.
- 성서 인용은 공동번역 원문을 확인하고 주보에 없는 순서(extra)는 제외한다. 본문·악보가 없을 때만 기존 외부 링크 대체를 사용한다.

## 주간 갱신
1. 인쇄된 주보의 예배 순서·교회소식을 읽고 관련 위키·용어집과 대조한다.
2. data/worship-order.json → node scripts/build-worship-slides.js → data/worship/YYYYMMDD.book.json 흐름을 따른다.
3. data/jubo/YYYYMMDD.json에 호수·날짜·표지·예배 시간·본기도를 기록한다.
4. data/jubo/index.json의 dates 맨 앞에 새 날짜를 넣는다.
5. data/bulletin-news.json, data/bulletin-verses.json, data/worship-texts/readings.json과 연결을 확인한다.
6. 성가 번호를 판별해 검증된 악보 이미지를 연결한다. data/hymnal-2015/index.json은 기존 자료의 색인일 뿐 새 PDF의 색인이 아니다.
7. npm test를 실행하고 tests/juboLinks.test.js·성가 이미지 관련 검사를 확인한다. 실행 불가 시 미실행을 명시한다.
8. 브랜치 → PR → 검증 → squash merge를 진행한다. 주보 등록의 공식 저장소 반영은 CLAUDE.md 절차를 따른다.

## 모바일 확인
- 320·390·412px에서 표지·탭·모든 항목 펼침·교회소식·안내를 확인한다.
- 글자 크기 3단계, 공유, 복사, 모두 펼치기/접기, 다크모드를 확인한다.
- 악보 비율과 모든 페이지, 회중 응답 강조, 기립 표시를 확인한다.
- 문서 전체를 스크롤한다. 중첩 스크롤, 가로 넘침, 글자 잘림, 버튼 겹침을 만들지 않는다.
- 관성 스크롤 중 scrollIntoView·탭 scrollLeft를 실행하지 않는다. scroll-behavior: smooth·backdrop-filter를 추가하지 않는다.
- 현재 본문 줄간격 1.65, 본기도 1.7, 응답 줄 여백 6px, 구분 .15em을 기준으로 유지한다.

## 배포와 검색
- 모바일 주보와 본문·성가 악보 이미지는 공개 저장소에 반영하고 GitHub Pages의 `/jubo/`에 웹 배포한다(사용자 명시 승인, 2026-11-01). 교우가 웹에서 열어 보도록 하되, 링크 안내는 비공개 교회 밴드에서만 한다. 공개 홈페이지 본문·메뉴·푸터·사이트맵·공개 게시물에는 모바일 주보 링크나 홍보를 추가하지 않는다. “홈페이지에 게시하지 않는다”는 웹 배포 금지가 아니라 홈페이지에서 연결·홍보하지 않는다는 뜻이다. 이 범위의 커밋·푸시·PR·머지는 기존 자동 처리 절차로 진행하며 공개 접근 가능성을 이유로 매번 재승인을 요청하지 않는다. 이 스킬 자체는 밴드에 메시지를 게시할 권한이나 자동 게시 지시가 아니다.
- 공개 홈페이지·메뉴·푸터·사이트맵·공개 게시물에 모바일 주보 링크를 추가하지 않는다.
- 기존 noindex를 유지한다. 공개 저장소·GitHub Pages 파일은 밴드에만 링크를 올려도 비공개가 되지 않는다.
- robots.txt 차단이나 링크 숨김만으로 검색 제외가 완료됐다고 말하지 않는다. PDF·이미지의 검색 제외에는 응답 헤더 또는 접근 제한 등 실제 제공 방식 확인이 필요하다.
- 완료 보고는 실제 변경·검증·머지 범위만 적고 주보 링크를 제공한다. 업로드·검색 제외·테스트가 미완료면 별도로 명시한다.

- **고령 교우의 화면 이동 최소화 (2026-11-01 사용자 확정)** — 예배 중 필요한 성경 말씀 전문·설교의 바탕 본문·기도문·성가 악보는 모바일 주보의 해당 항목 안에서 펼쳐 읽는다. 설교 항목에도 해당 성경 본문 전문을 표시한다. 실제 설교 원고 전문은 제공받은 경우에만 싣고 임의로 만들지 않는다. 악보를 눌러 새 탭·이미지 화면으로 이동시키지 않고 현재 화면에서 두 손가락 확대를 이용한다. 자료가 빠졌다고 외부 링크로 대체하지 말고 원문을 확보해 보완한다. 안내 영역의 선택적 외부 링크와 예배 중 필수 자료를 구분한다.
