# 성가 품질·보관 확인

확인일: 2026-11-01

## 품질

같은 성가 64·65가 들어 있는 페이지를 실제 비교했다. 기존 images/page-0073.jpg는 610×940 픽셀, 새 단성판 원본 111쪽은 1527×2352 픽셀이다. 새 단성판은 가로·세로 약 2.5배, 픽셀 수 약 6.3배로 확대 가독성이 낫다. 스캔이라 일부 선 끊김은 있으며, 새 전체판은 벡터 악보로 선명하지만 여러 성부·최종가편집본 표기를 확인하고 보완용으로 쓴다.

## 저장소 보관

실제 전송 요청은 16MiB 이하만 허용한다. 처음 만든 전체판 3분할 파일도 한도를 넘어 곡 시작 페이지에서 25개로 추가 분할했다. 단성판은 148/302/332쪽의 3개로 나눴다. 모든 PDF의 실제 페이지 수, 원본 범위 누락·중복, SHA-256, Git blob SHA를 확인했다. [원본 목록](sources/README.md)·[검증 정보](sources/manifest.json).

처음 만든 전체판 3분할과 단성판 원본 묶음은 별도 보존했다. 저장소에는 전송 가능한 작은 PDF 묶음을 보관한다. 새 원본 sources/ 폴더는 GitHub Pages 빌드에서 제외하고 홈페이지·사이트맵에 연결하지 않는다. 모바일 주보 noindex는 유지했다. 공개 GitHub 저장소 자체의 검색 비노출을 보장하는 설정은 아니다.

## 실제 주보 적용 범위

기존 주보 이미지 경로와 색인은 보존했다. 새 단성판 원본을 우선 사용하는 정책과 파일 보관은 반영했으나, 657곡 전체에 대한 새 이미지 색인 생성·일괄 교체는 이 업로드 작업에 포함하지 않았다. 매주 해당 곡의 번호·제목·페이지를 확인해 이미지를 연결한다.
