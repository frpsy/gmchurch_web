위 PDF 경로는 예정 파일명이며 아직 다운로드 링크가 아니다. 전체판 원본은 144,460,329바이트다. 곡 경계에서 나누고 각 파일 크기·원본 페이지 범위·해시를 확인한 뒤 이 표를 갱신한다. 곡을 중간에서 자르지 않는다.

기존 images/의 634쪽 자료는 상위 폴더의 manifest.json·index.json으로 관리한다. 새 PDF와 페이지 번호가 다르므로 별도 색인을 만든다. 자료명은 문서에서 ‘성가’로 쓰고 판은 단성판·전체판으로 구분한다.

원본을 공개 저장소에 올리면 비공개 밴드에만 링크를 배포해도 파일은 공개된다. 검색 제외는 별도 검증이 필요하다. 검색 제외 완료로 기록하거나 원본을 공개 링크로 안내하기 전에 제공 방식과 응답 헤더를 확인한다.
