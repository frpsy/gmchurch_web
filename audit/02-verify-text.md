## 4. 줄바꿈 CSS 시험 (TXT-42~49)

### 측정 방법
- 스크립트: `scratchpad/v3/lb.py`(측정), `an.py`(집계). 결과는 `scratchpad/v3/lb.json`.
- 20페이지 × 5개 폭(360, 390, 768, 1024, 1440) × 5개 변형. `<details>`는 모두 펼침. 각 변형은 `add_style_tag`로 주입 후 제거(소스 수정 없음).
- 대상 요소: `h1~h5, .links-card-name, .iona-link-card__desc, .footer-addr-link, .section-sub, .map-addr-text`. 문자별 `Range.getClientRects()`로 줄을 나눠 마지막 줄 길이를 측정.
- 고아 줄 정의: 2줄 이상이고 마지막 줄이 2글자 이하. 회귀 지표는 변형 후 줄 수 증가, 요소 높이 변화, 문서 가로 스크롤 신규 발생.

### 변형별 결과 (고아 줄 수, 전 폭·전 페이지 합계)

| 변형 | CSS | 고아 줄 | 줄 수 증가 | 높이 변화 | 신규 가로 스크롤 |
|---|---|---|---|---|---|
| base | (현재) | 26 (360px 5, 390px 1, 1440px 20) | - | - | - |
| A | `h1,h2,h3,h4 { text-wrap: balance }` | 21 (제목 5건 해결, 푸터·iona 남음) | 0 | 0 | 0 |
| **B** | `h1,h2,h3,h4,.links-card-name,.iona-link-card__desc,.footer-addr-link { text-wrap: balance }` | **0** | **0** | **0** | **0** |
| C | `h1,h2,h3,h4 { text-wrap: pretty }` | 22 (360px 1건 남음) | 0 | 0 | 0 |
| D | `.footer-addr-link { white-space: nowrap }` | 6 (푸터는 해결, 제목 6건 남음) | 0 | 40(푸터 줄 수 감소) | 0 |

- B 이후 마지막 줄이 4글자 이하인 요소도 푸터 외 0건(base는 360px 8, 390px 3, 768px 1, 1024px 1).
- 푸터 주소 줄 구성: 1440px base "경기도 광명시 아방리 2길 / 10" → B "경기도 광명시 / 아방리 2길 10". 1024px base "경기도 광명시 아방리 / 2길 10" → B "경기도 광명시 / 아방리 2길 10". 360~768px는 한 줄이라 변화 없음.
- `.links-card-name`: 390/768px "대한성공회 성 프란시스 수도회(네이버 / 지도)" → B "대한성공회 성 프란시스 / 수도회(네이버 지도)".

### D(푸터 nowrap)를 기각하는 이유
nowrap으로 주소가 한 줄이 되면 푸터 열 너비가 달라져 **다른 열이 밀림**. 1024px에서 주소 열 오른쪽 끝 532 → 559px, 다음 열 시작 580 → 607px. 푸터 전체 레이아웃 회귀이므로 쓰지 않는다.

### 권장안 (확정)
`style.css:95` 아래(기존 `p, li, blockquote { text-wrap: pretty; }` 바로 뒤)에 추가한다.

```css
/* 제목·푸터 주소의 마지막 줄 고아 방지 (미지원 브라우저는 무시) */
h1, h2, h3, h4,
.links-card-name, .iona-link-card__desc, .footer-addr-link { text-wrap: balance; }
```

- 브라우저 지원: balance는 Chrome·Edge 114, Firefox 121, Safari 17.5 이상. 미지원 브라우저는 속성을 무시하므로 기존 줄바꿈 그대로이고 레이아웃은 깨지지 않는다. `pretty`는 Firefox 미지원, Safari 26부터라 이번 목적에는 balance가 적합.
- 제약: Chromium은 6줄 이하에서만 balance를 적용(그 이상은 기존 줄바꿈). 현재 제목은 모두 3줄 이하라 해당 없음.
- 회귀 위험: 5개 폭 × 20페이지 × 5개 변형(기준 포함 500회 측정)에서 줄 수·높이·가로 넘침 변화 0. 다만 balance는 여러 줄 제목의 첫 줄을 짧게 만들어 **시각적으로 줄 길이가 고르게** 바뀐다(디자인 변화는 있음). 다크모드·인쇄 CSS는 측정하지 않음.
- 기존에 `text-wrap: balance`가 있는 `.section-sub`(`style.css:860`), `:2545`, `.map-addr-text`(`:3717`)와 충돌 없음.
- 영향 페이지: 전 페이지(푸터), `clergy`, `worship`, `news`, `videos`, `greenchurch`, `links`. `style.css`를 고치므로 모든 HTML의 `?v=` 갱신이 필요(CLAUDE.md 체크리스트).
- 테스트 영향: `tests/`에 CSS를 검사하는 항목이 없어 영향 없음.
