## 1. 개요

방법
- 정적 추출: `style.css`, `app.js`, `data.js`, `*.html`의 hex(3/6/8자리)·rgb(a)·hsl·이름 색·color-mix를 정규식으로 추출(스크립트는 작업 폴더). 총 372건, 서로 다른 값 157종. hsl 0건. HTML의 hex 20건은 대부분 `<meta theme-color>` 1건씩(`bulletin.html:8` 등)이며 본문 색 하드코딩은 없음.
- CSS 선언 파싱: 중첩 `@media` 문맥을 추적해 색 선언 292건을 분류(다크 블록 여부, 선택자).
- 유사색: CIEDE2000, ΔE < 3 연결 요소로 묶음(불투명 62종 대상).
- 렌더링 대비: Playwright Chromium, 20페이지 × 폭 390·1440 × 라이트·다크 = 80뷰. 텍스트 노드 8,962개마다 `elementsFromPoint`로 겹침 순서를 구해 배경을 합성, 텍스트·조상 opacity 반영, WCAG 2.x 대비 계산. 큰 글자(24px 이상, 또는 18.66px 이상 굵게)는 3:1, 그 외 4.5:1.
- 배경 이미지·그라데이션·사진 위 글자: 글자를 투명 처리한 풀페이지 스크린샷에서 글자 영역 픽셀을 표본 추출해 대비의 최솟값·하위 10%·중앙값을 구함(630건). 이는 근사치이므로 "수동 확인" 표기.
- 접힌 `<details>`·`.more-body[hidden]`는 펼친 상태로도 측정함(두 번째 패스).
- 절기: 현재(녹색) 외에 `data.js` 값으로 자색·금(백색)·적색 대비를 계산하고, 날짜를 고정(2026-12-10 대림, 2026-12-28 성탄, 2027-05-16 성령강림 전후)해 실제 렌더링도 측정함.

## 4. 미확인 항목

- `fixed/sticky` 요소(내비, 뒤로가기, 라이트박스) 480건은 픽셀 표본에서 제외. 계산값만 확인함. 내비 글자(`rgba(255,255,255,.85)`)는 `--nav-glass` 위에서 10:1 이상으로 추정되나 스크롤 중 아래 콘텐츠 비침은 미확인.
- 호버·포커스 상태 대비는 정적 계산(COL-05 등)만 했고, 실제 호버 렌더링은 측정하지 않음.
- 라이트박스(`#bulletin-lb`, `#portrait-lightbox`, `.gallery-lightbox`)는 열린 상태 미측정.
- 이미지 위 글자(약 1,100건)는 픽셀 근사. 사진 교체 시 값이 달라지며, 최종 판단은 수동 확인 필요.
- COL-04: `.step-num` 단독(절기 밖) 사용처가 현재 DOM에 없는지 확인하지 못함.
- COL-09: 계산상 통과하는데 픽셀 근사에서 근소 미달. 스크린샷 안티앨리어싱 영향 가능.
- 인쇄(`@media print`) 색상, 강제 색상(forced-colors) 모드는 범위 밖.
- 실기기(iOS Safari, 안드로이드) 렌더링은 미확인(헤드리스 Chromium 기준).
- 대림·사순(자색), 성주간(적색)의 직접 렌더링은 날짜 고정 3종(12-10, 12-28, 2027-05-16)에서만 확인했고 사순·성주간 날짜는 미실행(계산표로 대체).
