# 익명 조사 (survey/)

카카오톡 릴레이 명단 방식으로 하던 반복 조사(날짜·시간별 참석, 급식 인원, 돌봄 지원 등)를 링크 하나로 받는 익명 조사 페이지입니다. 빌드 없는 정적 페이지이며 Firebase(Firestore + Authentication)에 저장합니다. 사이트 메뉴에는 연결하지 않았고 검색 노출(`noindex`)도 막았습니다. 링크를 아는 사람만 접속합니다.

- 응답자: `survey/?s=조사ID` — 이름·연락처 없이 선택만 합니다. 익명 로그인 uid 하나당 응답 1건이며, 같은 기기에서는 답변을 고칠 수 있습니다.
- 관리자: `survey/` — Google 로그인 후 조사 만들기·수정·복제·마감·삭제·결과 확인.
- 문항 유형: 여러 개 선택 / 하나만 선택 / 항목별 인원수 입력(급식 신청 인원 등). 날짜·시간 선택지는 자동 생성 도우미로 만듭니다.
- 반복 조사: 목록에서 `복제`하면 같은 문항으로 새 조사가 만들어집니다.
- 의견란을 켜면 관리자만 읽을 수 있습니다. 연락처가 필요하면 응답자가 의견란에 스스로 적게 안내해 주세요.

## Firebase 설정 (한 번만)

1. Firebase 콘솔 > 빌드 > **Firestore Database** 만들기 (프로덕션 모드)
2. 빌드 > **Authentication** > 로그인 방법에서 **익명**과 **Google**을 사용 설정
3. Authentication > 설정 > 승인된 도메인에 `frpsy.github.io` 추가
4. 프로젝트 설정 > 내 앱 > 웹 앱을 만들고 `firebaseConfig` 값을 `survey/firebase-config.js`에 붙여 넣기
5. Firestore > 규칙 탭에 `survey/firestore.rules` 내용을 붙여 넣고 게시
6. Firestore에서 컬렉션 `admins`를 만들고, **문서 ID를 관리자 Google 이메일**로 한 문서를 추가 (필드는 아무거나 1개). 이 목록에 있는 계정만 조사를 만들 수 있습니다.

`firebase-config.js`가 비어 있으면 이 브라우저에만 저장되는 체험 모드로 동작하니, 설정 전에 화면을 먼저 확인할 수 있습니다.

## 한계

- 익명이므로 누가 응답했는지, 중복 응답(다른 기기·시크릿 창)을 막을 수 없습니다. 기기당 1건만 보장합니다.
- 정원 제한(선착순 마감)은 지원하지 않습니다.
