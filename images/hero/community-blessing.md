# 공동체 상단 이미지

사용자가 제공한 숲속 반려견 축복 사진을 바탕으로 이미지 생성 도구에서 보정한 홈페이지 장식 이미지입니다. 사제님과 반려견의 얼굴·표정·자세를 유지하도록 요청하고, 뒤쪽 인물과 숲 배경에 약한 아웃포커싱과 최소한의 색감 보정을 적용하고 오른쪽 기둥을 제거했습니다. 다른 메뉴와 같은 헤더 높이에서 두 대상이 보이도록 가로 여백을 확장했습니다. 원본 기록 사진은 별도로 유지합니다.

- `community-blessing.webp`: PC용, 2048×683
- `community-blessing-m.webp`: 모바일용, 1200×400
- 적용 위치: `community.html`, `.page-hero--community`
- 제목과 설명은 기존 HTML 텍스트를 유지합니다.
